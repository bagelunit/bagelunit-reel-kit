# logos

Other companies' and apps' logos that this brand's reels use, one SVG each, listed in `index.json`. The kit ships none: you add the ones you need with `/logo-library`.

Each logo has a **fidelity** (`official`: the brand's own artwork, `traced`: redrawn from a clear crop, `approx`: a stand-in) and **rights** (`approved`: you read the usage terms and approved that mark, `test-only`: fine in a test, never posted, `pending`: not decided). The scheduler refuses to post a reel that uses a logo that is not official or traced and approved (house rule 9). Do not edit `index.json` by hand: use `/logo-library`.
