# broll

Short video clips that sit behind or between shots: hands at work, a street, a shop floor, a close-up of a tool.

- **Formats:** MP4 (H.264) or MOV. Vertical 1080x1920 preferred; horizontal is fine if it can be cropped.
- **Size limits:** under 8 seconds and under 50 MB per clip. Trim before you drop it in.
- **Naming:** `topic-what-it-shows-01.mp4`, lowercase, dashes, no spaces (for example `kitchen-prep-hands-01.mp4`).
- **Rights:** only footage the brand shot itself or has a licence to use. No clips ripped from other accounts or from stock sites without a licence. A person who can be recognised needs their OK.
- Add a row to `../INDEX.md` for every file. The media files stay out of git; this README and the index stay in.
