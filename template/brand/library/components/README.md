# components

Reusable pieces the brand wants in many reels: a logo sting, a badge, a hand-drawn arrow, a stamp, a lower-third strip.

- **Formats:** SVG (best), or PNG with a transparent background. Short animated pieces as WEBM or MOV with alpha.
- **Size limits:** under 2 MB each; animated pieces under 5 s and 10 MB.
- **Naming:** `kind-name-01.svg` (for example `stamp-approved-01.svg`).
- **Rights:** only things the brand made or may use. Fonts, icons and artwork from elsewhere need a licence that allows use in video.
- Add a row to `../INDEX.md` for every file. The media files stay out of git; this README and the index stay in.
