# Fonts for the dashboard

Poppins, designed by Indian Type Foundry (https://fonts.google.com/specimen/Poppins). Latin subset, woff2, weights 400, 500, 600 and 800, bundled unmodified so the dashboard looks the same offline and on any host.

Licensed under the SIL Open Font License 1.1 (full text in `OFL.txt`). The OFL allows bundling the fonts with software, including sold software, as long as the fonts are not sold on their own.
