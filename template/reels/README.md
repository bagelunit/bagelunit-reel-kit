Reels made in this brand workspace: one folder per reel, reels/<slug>/, holding script.txt, STORYBOARD.md, approvals.md and out/<name>.mp4, out/cover.jpg and out/caption.txt.
Heavy files (frames, drafts, renders) go in build/ inside each reel, or in the work_dir set in brand/brand.json for HyperFrames projects.
reels/_example/ is a blank pattern for a script, approvals and caption; it is never a real reel.
Its caption.txt is the pattern for a reel's out/caption.txt.
