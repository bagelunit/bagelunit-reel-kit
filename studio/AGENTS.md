# BagelUnit Reel Kit · for Codex, Cursor and other agents

The engine is installed once as the `bagelunit-reels` skill. Reels are made in a brand folder (made by `/brand-setup`), not in this folder. Any request for a reel, short, TikTok, explainer, talking-head edit or other social video starts in `KIT.md` (same folder as this file). It is the studio's complete procedure, from the setup check to the exported mp4; work through it in order and open each guide it names before you write code.
