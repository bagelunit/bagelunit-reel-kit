# Local changes to the BagelUnit Reel Kit engine (formerly Susanoo Reel Kit) (keep this list when the engine is updated)

1. 2026-11-05 · KIT.md section B: always ask the user which style (Print / 3D / Talking head) before a reel. Owner rule.
2. 2026-11-05 · Picture-sticker presenter for print reels (a brand's own pose set, 19 poses):
   - NEW `modes/print/runtime/stickerhost.js` (whole file is ours).
   - `modes/print/runtime/load.js`: loads stickerhost.js after presenter.js.
   - `modes/print/runtime/engine.js`: `applyReelSettings()` calls `STICKER_HOST.setup(REEL)`; `guy()` draws the sticker
     instead of the code bust when reel.json "presenter".type is "stickers".
   - The installed copy keeps the originals as `*.orig-2026-11-05` next to each file; the repo does not ship them (diff against the original kit instead).
   - Use: reel.json "presenter": {"type": "stickers", "dir": "host", "cues": [[word, pose, nth]]}; the reel's `host/` folder
     holds the pose PNGs (each brand keeps its own set outside the repo; see docs/avatar.md).
   - Defaults: height 600, lift 120 (owner 2026-11-05: the chest logo must always be visible inside the frame). Poses include `raise` (finger up, the old idle).
3. 2026-11-05 · Real-recording sound step (owner: kit's synthesised effects sound fake; A/B: real 0.64 vs synth 0.05 realness):
   - NEW `tools/realsound.py` (ours): thins build/sfx.json, snaps cues to the picture with opus-sound-layer qa.py's own
     motion definitions (move = peak, cut = hard change, land = motion stops, else appear = the slam frame), mixes with
     opus-sound-layer mix.py (~/dev/sound/opus-sound-layer, library in audio/kit), muxes, listens with earshot.
   - `KIT.md` section G step 5: run it after `kit export`.
   - Needs ~/dev/sound/opus-sound-layer (library built) and ~/dev/sound/earshot (.venv). Run with earshot's Python.
   - realsound.py --hits louder|softer (default louder: hits mixed as hero; owner 2026-11-05).
4. 2026-11-05 · Susanoo Reel Kit repo: this folder ships as `studio/` in the repo and is installed to `~/.claude/skills/susanoo-reels`
   by `setup/install.sh`. `CHANGELOG.md` is the engine's changelog up to v1.4.1.
5. 2026-11-05 · Rebrand to Susanoo Reel Kit, with the creator's written permission: product name, skill name
   `susanoo-reels`, install path `~/.claude/skills/susanoo-reels`, settings folder `~/.config/susanoo-reels/` (tools fall back to the pre-rebrand folder until `setup/install.sh` copies it over),
   page titles, file headers, the render lock file name and the example handles. Behaviour unchanged.
6. 2026-11-06 · Cross-platform: `tools/voicebank.py` plays the voice preview on Windows (default player) and Linux (ffplay, mpv, paplay or aplay) as well as Mac (afplay); `tools/realsound.py` finds earshot at `.venv/Scripts/earshot.exe` on Windows. Behaviour on Mac unchanged.
7. 2026-11-06 · NEW `tools/budget.py` (ours): counts a script's characters and compares them with the ElevenLabs credits left (a free read of your own subscription; the key is never printed). Run before Gate A.
8. 2026-11-07 · NEW `tools/qa.py` (ours): final-file checks with ffmpeg and ffprobe only. Format (1080x1920, 30 fps, h264 and aac, length against `audio/vo.mp3`), loudness (-15 to -9 LUFS, true peak at most -1 dBTP), black and frozen stretches over 0.5 s, first-word sync (80 ms), and text size and safe area (SKIPPED unless `build/text_boxes.json` exists). Prints `QA: PASS|FAIL`, writes `build/qa.json`. Registered as `kit qa`.
9. 2026-11-07 · NEW `tools/gate.py` (ours): `kit gate <dir> record|check [--gate A|B|C] [--note ...]`. Gate C stores the first 12 characters of the final mp4's SHA-256, the QA result and the latest `Review:` line under `## Gate C` in `approvals.md`; `check` prints MATCH or CHANGED SINCE APPROVAL. No network.
10. 2026-11-07 · Paid-call guard. NEW `tools/markers.py` (ours). `tools/voice.py` and `tools/take.py` now import it and hash every paid request into `build/.markers/<stage>.json`: the same request again prints "reused (no credits spent)", a request that may already have been billed is refused until `--force`. NOTE: `voice.py` and `take.py` now differ from the upstream kit. A kit update must re-apply these edits and keep `markers.py`.
11. 2026-11-07 · NEW `tools/lint.py` (ours), `kit lint`: shot grammar from `build/shots.json`, the talking mode's `motion_mask.json` or the depth mode's `cuts.js`. Codes SHOT-LEN, FACE-LEN, ADJ-SAME, CUT-WORD, RHYTHM, FIRST-MOVE (errors) and DEVICE-REPEAT (warning). Print mode publishes no shots yet, so it checks nothing there. To fix: have the print page publish a `shots` list and have `session.mjs` write `build/shots.json`.
12. 2026-11-07 · Pre-posting estimator (ours): NEW `tools/measure.py` (facts only, `build/measure.json` and contact sheets), `tools/calibrate.py` (ridge fit on a brand's own Instagram Insights CSV, refuses under 8 measured reels, saves `~/.config/susanoo-reels/predict-model.json`), `tools/predict.py` (measurements only until a model exists, never invents numbers). Registered as `kit measure`, `kit calibrate`, `kit predict`.
13. 2026-11-07 · `tools/kit.mjs`: six new rows in the COMMANDS table (`lint`, `qa`, `gate`, `measure`, `calibrate`, `predict`). `KIT.md` section G: lint, steps 6 and 7 and the paid-call note.
14. 2026-11-07 · Fact check (ours): NEW `tools/facts.py`, `kit facts <dir> check|record [--scope script|final]`. The mechanical half needs no network (digits against `brand/facts.md`, sources and cleared dates, 30-day staleness, leftover `{{needs cleared fact}}`, absolute wording, nearest facts row per script sentence; writes `build/factcheck.md`). `record` stores a PASS or FAIL from the fresh re-read (`/reel-factcheck` in the template) with a fingerprint of the words and the facts table in `build/facts_check.json` and a line under `## Fact check` in `approvals.md`. `tools/gate.py` now imports `facts.py` and refuses Gate A (scope script) and Gate C (scope final) without a current PASS; `--skip-facts "reason"` overrides and is logged. `KIT.md` section G step 5b. A kit update must keep both edits.
15. 2026-11-08 · `KIT.md` section B: the style question is asked with the AskUserQuestion tool (a question block with options and "Other"), not as plain text. Owner rule.
16. 2026-11-08 · Rename to BagelUnit Reel Kit (owner decision): skill name `bagelunit-reels`, install path `~/.claude/skills/bagelunit-reels`, settings folder `~/.config/bagelunit-reels/`. `kitcore.py`, `take.py`, `checkup.mjs` and `kit.mjs` fall back to `~/.config/susanoo-reels/` until the installer copies it over. Copyright stays Susanoo Inc. Behaviour unchanged.
17. 2026-11-08 · `tools/kit.mjs` `start`: copies the mode's starter without overwriting files already in the folder (`fs.cpSync` with `force: false`), lists what it kept, and says "check script.txt" instead of "write script.txt" when one was there. Before this, a `script.txt` written before Gate A was replaced by the sample script if `kit start` ran afterwards. A kit update must keep this edit.
18. 2026-11-08 · Node.js 22 or newer (Node 20 reached end of life in April 2026; CI now tests 22). `tools/checkup.mjs` checks for 22, `package.json` and the lockfile root say `"node": ">=22"`, `SETUP.md` says 22. The repo's installer and launchers say the same, and point Linux users to nodejs.org because the apt `nodejs` package is too old on most versions.
19. 2026-11-09 · `tools/kit.mjs` `start`: refuses a reel folder that is not inside a set-up brand folder (the nearest folder above it holding `brand/brand.json` with a name and `.kit-version`), and notes when the brand folder's name does not end in `-reels`; `--anywhere` skips the check for tests. `KIT.md` section D: reels are made only in the brand's `<brand>-reels` folder, never a fallback `./reels/`. Owner rule.
